# Editing this site

This is the 1000 Errors website (1000errors.uk), served by GitHub Pages from the `main` branch. A push to `main`
goes live in a minute or two. It's also edited from a PC, so the PC fetches from GitHub before it changes anything.

## Fine to edit here
Page wording, layout and styles (`index.html`, the page folders, `styles.css`, `custom.css`, `custom.js`), new pages,
blog posts, and non-product images in `assets/` (give images a descriptive file name and alt text).

## Don't edit here (made by scripts on the PC from the product catalog)
`products.js`, `checkout.json`, `products.xml`, `sitemap.xml`, `assets/products/`, `pinterest/`, `CNAME`, `.nojekyll`.
Product, price, size or stock changes also have to match the Etsy shop, so they are done on the PC. If asked for one,
don't change these files: say it needs the PC and suggest adding it to the To do list.

## How to work
- Propose new or changed wording first and only edit once it's approved.
- Commit straight to `main` with a short plain message saying what changed (no pull requests or branches needed),
  then push. Pull first if the push is refused (a daily job also commits here).
- Keep the location as just "Bristol".
- Afterwards, say what changed and the page link on 1000errors.uk.
